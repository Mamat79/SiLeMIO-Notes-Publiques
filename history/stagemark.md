# StageMark 2027.1.17 · macOS

## Français

- En ouvrant un projet StageFlow local ou LIVE, retrouvez un plan par groupe dans **Plan affiché** et **Plans**, avec les noms et l’ordre de StageFlow. Les dessins existants sont conservés et vous pouvez ajouter des plans libres.
- L’image, les repères et les tracés du Rider importé s’affichent sur le canevas de son groupe. **Modifier le plan partagé** permet de modifier le dessin, de redimensionner l’image, d’en régler la luminosité ou de la masquer en préservant les coordonnées des repères et tracés.
- **Ouvrir StageMark** dans StageFlow reprend le projet et son groupe actif sur le même Mac. Avec **StageFlow 2027.1.27 pour Mac**, les réglages d’image sont partagés en LIVE. Après une pause, choisissez de recevoir la version de la session ou d’envoyer vos modifications.

## English

- Open a local or LIVE StageFlow project to see one plan per group in **Visible plan** and **Plans**, using StageFlow’s group names and order. Existing drawings are kept and you can add unlinked plans.
- The imported rider image, markers and paths appear on the group’s canvas. Use **Edit shared plan** to edit the drawing, resize or dim the image, or hide it while preserving marker and path coordinates.
- **Open StageMark** in StageFlow opens the project and its active group on the same Mac. With **StageFlow 2027.1.27 for Mac**, image settings are shared over LIVE. After pausing, choose whether to receive the session version or send your edits.

## v2027.1.12 · 2026-11-19 · unspecified · original

# StageMark 2027.1.12 · Windows

Après la saisie du code LIVE et la confirmation d’enregistrement éventuelle, StageMark ouvre directement le projet de la session dans l’éditeur. Un plan est disponible pour chaque groupe. Les modifications des plans StageMark sont envoyées à la session et les révisions reçues s’affichent automatiquement hors conflit. Si deux postes modifient la même révision, les modifications locales restent disponibles pour examen ou copie.

Avec un hôte StageFlow compatible, ouvrez **Patch → groupe → Modifier le plan partagé** pour voir et déplacer les repères du dessin Rider. Les deux éditeurs lisent la même révision, y compris sur des PC différents.

After entering a LIVE code and completing any save prompt, StageMark opens the session project directly in the editor. Each group has a plan. StageMark plan edits are published to the session, and incoming revisions appear automatically when there is no conflict. If two workstations edit the same revision, local edits remain available for review or saving a copy.

With a compatible StageFlow host, open **Patch → group → Edit shared plan** to view and move markers on the Rider drawing. Both editors read the same revision across workstations.

La recette croisée a vérifié le transfert dans les deux sens sur un PC Windows avec les composants réseau réels. Les scénarios de liaison sur deux PC physiques et la projection restent à vérifier sur place. Les paquets macOS sont disponibles dans la [version 2027.1.11](https://github.com/Mamat79/StageMark/releases/tag/v2027.1.11).

Cross-application testing verified transfers in both directions on one Windows PC using the real network components. Two physical PCs and projection hardware remain to be checked on location. macOS packages are available in [version 2027.1.11](https://github.com/Mamat79/StageMark/releases/tag/v2027.1.11).

# StageMark 2027.1.11

## Français

- **Plan de groupe partagé avec StageFlow.** Ouvrez le même projet local `.stageflow`, puis choisissez **Patch → groupe → Modifier le plan partagé**. La fiche technique du groupe sert de fond et peut être masquée.
- **Édition du plan.** Choisissez les micros à placer. Déplacez ou supprimez les repères, les contours et leurs points. Les deux applications relisent le même dessin et signalent les modifications concurrentes.

## English

- **Group stage plan shared with StageFlow.** Open the same local `.stageflow` project and choose **Patch → group → Edit shared plan**. The group's rider is available as a background and can be hidden.
- **Plan editing.** Choose the microphones to place. Move or remove markers, outlines and their vertices. Both applications read back the same drawing and report concurrent edits.
- **Local workflow.** Edit the shared drawing in its own window. Manage metric stage settings, calibration and projection output in StageMark.
- **Project file monitoring.** StageMark keeps watching the main folder when new project folders appear.
